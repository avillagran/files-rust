# Lossless path text on NODE

`CopyPath` exports the same text that the address editor understands. Absolute UTF-8 paths without controls stay literal, including Unicode, percent signs and backslashes. Paths containing non-UTF-8 bytes or controls use an explicit local `file://` URI. Percent decoding occurs once, only for an explicit URI. Presentation escapes such as `\\xFF` are never decoded as path bytes.

The shared copy method validates loaded state, focus bounds, hidden visibility and current listing order before exporting. It never falls back to another focus or marked entry. Map retains its existing focus semantics and dispatch guards. Encoding failure reports an error before invoking the clipboard sink. Successful export uses the existing informational notice, preserving any operation error and avoiding an artificial error that disables unrelated actions. The native action calls FLTK's existing text-copy API; no file MIME ownership, move authority or native clipboard-delivery fix is claimed.

Address input permits at most `3 * 4096 + 7` encoded bytes only when the prospective edited text begins with `file://` (case insensitive). Literal paths and other editors retain 4096 bytes. The URI decoder still enforces its raw 4096-byte local-path bound and rejects remote hosts, NUL and malformed encodings. Edit preflight occurs before history allocation or mutation; IME replacement and undo retain the existing cursor transaction. Undo history retains its existing 32 KiB bound. URI representation does not imply that the host filesystem can create a component or path of that length.

The private scene fixture captures the shared method's text into an isolated sink, enters that text into the actual address editor and commits directory navigation. It records raw path hex because JSON paths cannot directly represent arbitrary Unix bytes. It does not acquire or inspect the user's clipboard. `scripts/copy-path-ui-check.py` owns its directories, configuration and windows and checks List/Dual raw-byte navigation and unchanged payloads.

Verification receipts and retained failures are in `docs/evidence/copy-path`. Internal handlers and framebuffer captures do not establish native keyboard/mouse input, clipboard delivery, accessibility, 2x rendering, all OS support, resource usage or startup performance. The FULL persistent goal and ROADMAP remain active; preview-format and resource experiment freezes remain in force.
